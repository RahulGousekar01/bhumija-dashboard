# Bhumija Dashboard — T-1 governance view

React + TypeScript dashboard module for the Bhumija Mining Management Portal
(Directorate of Mines & Geology, Government of Goa). It is built for daily
review of **previous-day (T-1) consolidated data** by department officers,
auditors and lessees. Light theme only, primary `#FF6B72`.

```bash
npm start        # standalone prototype (sample data) on http://localhost:3000
npm run build
```

To embed it in `bhumija-react-app`, follow [integration/README.md](integration/README.md).

## What's on the page

Top to bottom, in the order an officer works:

1. **Data-as-of bar.** "Data as of: Yesterday, 27-Oct-2026 · 23:59 IST", the batch ID and sync time, and how many sources are reconciled. A source list opens inline. Below that are an as-of date picker for archived snapshots and **Generate report**.
2. **Filter bar** (sticky):
   - reporting period: T-1 / 7D / 30D / MTD / FY / custom range
   - district › taluka, with a breadcrumb
   - party search
   - **compare with** previous day / last week / last month
   - removable chips
3. **KPI ribbon:** revenue against target (bullet bar), ore dispatched, permits issued, approvals past 7 days, open discrepancies, permits expiring. Each shows its change vs the comparison period, the T-1 day vs the 7-day average, and a sparkline. Values that depend on a late source are tagged **Provisional**. Clicking a KPI opens the matching queue or register filter.
4. **Overview panels:**
   - **Trend vs baseline:** daily bars with a 7-day average; late-batch days are hatched.
   - **Permit status by type:** uses the portal's status colours.
   - **Jurisdiction rollup:** heat-shaded, with drill-down.
   - **Collection by fee head.**
   - **Ageing & SLA:** open items by age, with breaches.
   - **Discrepancy register preview.**
5. **Work area** (tabs):
   - **Review queue:** open items, oldest first.
   - **Register:** all records.
   - **Module summaries:** stock, processing, dumps, payments and so on.
   - **Sign-off:** daily review sign-off per jurisdiction.

   The register has quick search, record-type and status chips, "with discrepancies" and "provisional only" toggles, sortable columns, paging, and PDF/Excel export of the current view.
6. **Record drawer:** opens at 60–70% of the viewport on desktop and full width on mobile, with no modals.
   - **Tabs:** Summary (details and workflow timeline), Reconciliation (source comparison and discrepancies), Fee heads, Audit trail (append-only).
   - **Footer actions:** **Mark reviewed** and **Flag discrepancy** (inline, mandatory remark, ACK number), plus record-sheet PDF/Excel.
   - **Navigation:** Previous/next (J/K), expand, Esc to close. The open record is kept in the URL.

Official reports use your existing `jspdf` / `jspdf-autotable` / `xlsx` versions. Each carries:
- DMG letterhead and logo
- reference number `DMG/BHU/<code>/<YYYYMMDD>/<seq>`
- data-as-of date and batch
- generated by (name, designation) and generated at
- the filters applied
- page numbers and a computer-generated footer

Every export is logged to the audit trail.

## Roles

| | Officer | Auditor | Party |
| --- | --- | --- | --- |
| Scope | All jurisdictions | All jurisdictions | Own organisation |
| Mark reviewed / sign off | ✓ | — | — |
| Flag / update discrepancies | ✓ | ✓ | — |
| Audit trail | ✓ | ✓ | — |
| Reports | ✓ | ✓ | ✓ |

In the standalone prototype the "View as" switcher in the header changes the role. Inside the portal, the role comes from the session.

## Structure

```
src/
  types/            dashboard.ts (module data), governance.ts (T-1, register, audit)
  services/         dashboardApi.ts (contract + mock), mock/ (sample data incl. T-1 register)
  context/          DashboardProvider: role, filters (URL-synced), officer, status colours
  hooks/            data loading, drawer URL state
  lib/              dates (IST, DD-MMM-YYYY), reports/official.ts (PDF/Excel), format, CSV, URL
  components/ui/    SlideOver, Tabs, ChartFrame, Sparkline, Toast, controls
  components/layout AppShell: standalone stand-in for the portal header + icon side nav
  features/governance/  as-of bar, filters, KPIs, overview panels, register, drawer, sign-off, report templates
  features/items|details|shared/  module summaries (stock, processing, dumps, …)
  pages/DashboardPage.tsx
integration/        drop-in files and backend contract for bhumija-react-app
```

## Prototype notes

- All data is sample data and is filtered in the browser to simulate the server.
  - The register is generated deterministically for the 60 days to the latest T-1.
  - Daily series follow Goa's mining season, with the monsoon break from June to September.
  - Actions (review, flag, sign-off) persist until the page is reloaded.
- **Archived as-of dates:** the register is aged back from the latest day rather than read from a real snapshot.
- **PDFs:** the built-in fonts cannot draw ₹, so PDFs print "Rs." Excel files keep ₹.
- **Original code:** the earlier JavaScript version is in `legacy-src-backup/`.
